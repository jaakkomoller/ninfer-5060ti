### Plain English Explanation

This regular expression matches a **URL** (or a domain name) that ends with one of three specific top-level domains: `.com`, `.org`, or `.io`.

Here are the specific rules it enforces:
1.  **Protocol is optional:** It can start with `http://` or `https://`, or it can omit the protocol entirely (e.g., `example.com` is valid, `example` is not).
2.  **`www` is optional:** It can include `www.` before the domain name, or it can omit it.
3.  **Domain name:** Must consist of lowercase letters, numbers, or hyphens (`[a-z0-9-]+`).
4.  **Top-Level Domain (TLD):** Must be exactly `.com`, `.org`, or `.io`.
5.  **Path is ignored:** The regex does **not** capture or validate any path after the domain (e.g., `/products`). It allows an optional `/` after the domain, but doesn't store it.
6.  **Query string:** If present, it must start with `?` and can contain any characters except `#`.
7.  **Fragment:** If present, it must start with `#` and can contain any characters.
8.  **Strict boundaries:** The `^` and `$` anchors ensure the *entire* string must match this pattern. No extra characters are allowed at the start or end.

---

### Example Strings

#### ✅ Matches
```text
https://my-site.org?user=123#profile
```
*   **Why:** It has `https://`, no `www`, a valid domain `my-site`, a valid TLD `.org`, a query string `?user=123`, and a fragment `#profile`.

#### ❌ Does Not Match
```text
http://example.net
```
*   **Why:** The TLD is `.net`, but the regex only allows `.com`, `.org`, or `.io`.

---

### Group Descriptions

The regex uses **capturing groups** (parentheses `(...)`) and **non-capturing groups** (parentheses `(?:...)`). Only the capturing groups are stored for later use.

| Group # | Pattern | Description |
| :--- | :--- | :--- |
| **1** | `([a-z0-9-]+)` | **Domain Name:** Captures the main part of the domain (e.g., `my-site` in `my-site.org`). It must be one or more lowercase letters, digits, or hyphens. |
| **2** | `(com\|org\|io)` | **Top-Level Domain (TLD):** Captures the TLD without the dot (e.g., `org` in `my-site.org`). It must be exactly `com`, `org`, or `io`. |
| **3** | `([^#]*)` | **Query String:** Captures the query parameters (e.g., `user=123` in `?user=123#profile`). It matches any characters *except* `#`. If no query string exists, this group is `null` or empty. |
| **4** | `(.*))` | **Fragment:** Captures the fragment/anchor (e.g., `profile` in `?user=123#profile`). It matches any characters after the `#`. If no fragment exists, this group is `null` or empty. |
