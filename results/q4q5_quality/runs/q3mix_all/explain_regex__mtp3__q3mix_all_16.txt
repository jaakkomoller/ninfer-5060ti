### Plain English Explanation

This regular expression matches a **URL** that points to a website with a specific domain name and one of three specific top-level domains: `.com`, `.org`, or `.io`.

Here’s the breakdown in plain English:
1.  **Protocol (Optional):** It may start with `http://` or `https://`.
2.  **Subdomain (Optional):** It may include `www.` before the main domain.
3.  **Domain Name (Required):** It must have a domain name consisting only of lowercase letters (`a-z`), digits (`0-9`), and hyphens (`-`).
4.  **Top-Level Domain (Required):** The domain must end with exactly `.com`, `.org`, or `.io`.
5.  **Path (Optional):** There may be a `/` followed by nothing (or it can be omitted entirely).
6.  **Query String (Optional):** There may be a `?` followed by any characters (except `#`) representing query parameters.
7.  **Fragment (Optional):** There may be a `#` followed by any characters representing a fragment/anchor.

**Key Constraints:**
- The domain name part **cannot** contain uppercase letters, underscores, or other special characters.
- The TLD is restricted to only `.com`, `.org`, or `.io`. Other TLDs like `.net`, `.edu`, or `.dev` will **not** match.
- The entire string must match from start to finish (due to `^` and `$`).

---

### Example Strings

#### ✅ Matching String
```
https://www.example-site.org?query=123#section
```
**Why it matches:**
- Starts with `https://` (optional protocol).
- Has `www.` (optional subdomain).
- Domain is `example-site` (only lowercase letters and hyphens).
- TLD is `.org` (one of the allowed TLDs).
- Has a `/` (optional, present here).
- Has `?query=123` (optional query string).
- Has `#section` (optional fragment).
- Matches the entire pattern from start to end.
