### Plain English Explanation

This regular expression matches a **URL** that points to a website with a specific domain name and one of three specific top-level domains: `.com`, `.org`, or `.io`.

Here is the breakdown of what it allows:
1.  **Protocol**: It optionally starts with `http://` or `https://`. If neither is present, it’s treated as a relative URL or just the domain.
2.  **Subdomain**: It optionally includes `www.` before the main domain.
3.  **Domain Name**: It requires a domain name consisting only of lowercase letters (`a-z`), digits (`0-9`), and hyphens (`-`). It does **not** allow uppercase letters, underscores, or other special characters in the domain part.
4.  **Top-Level Domain (TLD)**: The domain must end with exactly `.com`, `.org`, or `.io`. Other TLDs like `.net`, `.edu`, or `.co.uk` will **not** match.
5.  **Path**: There is an optional `/` after the domain, but **no path is allowed**. If you include any characters after the domain (like `/about` or `/products`), the match will fail.
6.  **Query String**: Optionally, it can include a `?` followed by any characters (except `#`) as the query string.
7.  **Fragment**: Optionally, it can include a `#` followed by any characters as the fragment (anchor).

**Key Limitations:**
- Only matches `.com`, `.org`, or `.io` domains.
- Domain names must be lowercase alphanumeric with hyphens only.
- No path segments are allowed (e.g., `example.com/page` will **not** match).
- Uppercase letters in the domain are not allowed.

---

### Example Strings

#### ✅ Matching String
```
https://my-site.org?query=123#section
```
**Why it matches:**
- Starts with `https://` (optional, allowed).
- No `www.` (optional, allowed).
- Domain `my-site` uses only lowercase letters and a hyphen (valid).
- TLD is `.org` (one of the allowed TLDs).
- No path (allowed).
- Query string `?query=123` is present (optional, allowed).
- Fragment `#section` is present (optional, allowed).
- Ends at the end of the string (`$`).

#### ❌ Non-Matching String
```
http://example.net/path/to/page
```
**Why it does NOT match:**
- The TLD is `.net`, but the regex only allows `.com`, `.org`, or `.io`.
- Additionally, it includes a path `/path/to/page`, which the regex does not allow (it expects the string to end after the domain, query, or fragment).

### Group Descriptions

The regex has **three** capturing groups (parentheses without `?:`):

| Group | Pattern | Description |
|-------|---------|-----------|
| **Group 1** | `([a-z0-9-]+)` | Captures the **domain name** (the part before the TLD). It must consist of one or more lowercase letters, digits, or hyphens. Example: in `my-site.org`, Group 1 captures `my-site`. |
| **Group 2** | `(com\|org\|io)` | Captures the **top-level domain** (TLD). It will be exactly `com`, `org`, or `io`. Example: in `my-site.org`, Group 2 captures `org`. |
