## 4. Phase 3 (DONE, uncommitted) — honest memory reservation

**Root cause (fully measured):** the planner reserved *requested* arena sizes, but the CUDA driver
charges the next **2 MiB multiple** of every `cudaMalloc` (verified 11 MB–600 MB on this card,
CUDA 13.1; probe: `cudaMemGetInfo` deltas always exactly `ceil2MiB(requested)`). The 4 MiB "graph
allowance" was actually the lazy module code loads: 2,097,152 B at startup warmup (T=4 decode set)
+ 2,097,152 B at first prefill (chunk-sized T); long-context decode and later prefills load
nothing further (a 3102-token prefill kept the total at exactly 4,194,304 B); `cudaGraphInstantiate`
itself ≈ 0 B. The old "343,040 B delayed charge" was the weights-arena rounding
(16,288,236,544 → 16,288,579,584) and is already inside the measured post-weights free.

**Changes (permanent — keep):**
- `src/core/arena.h`: `kDriverAllocationGranularity` (2 MiB) + `device_allocation_bytes()`.
- `src/runtime/contract/types.h`: `SequenceCapacityCurve::exact_reservations` — exact per-page
  table (index = pages − min; strictly increasing; empty = affine; other targets unaffected).
- `src/runtime/engine/kv_capacity.cpp`: table validation; `reservation_bytes()` prefers the table;
  Automatic mode binary-searches the table (affine closed form retained for tableless curves).
- `src/targets/qwen3_6/impl/runtime/layouts_impl.h`: `device_reservation_bytes` now
  `device_allocation_bytes()`-rounded for persistent/workspace/request-transient; MTP 4 MiB
  allowance comment rewritten with measured provenance; curve built with the exact table
  (`build_sequence_candidate` per page, monotonicity-checked). This is shared family code → 27B
  and 35B-A3B both get honest reservations. (qwen3.5-9B has its own planner, untouched.)
- `src/targets/registry.cpp`: preflight now uses `free − device_allocation_bytes(weight_bytes)`
  so preflight and the post-weights check agree.
- `tests/test_kv_capacity.cpp`: exact-table cases (largest-fitting search, explicit mode,
  base/span/monotonicity validation). All green.

**Verified:** 3232 → clean rejection *before* the 15 GB upload (`requires 188743680, but only
187760640`); 4096 → same clean rejection (`218103808`); 3200 → generates, summary shows
`runtime reservation 178.00 MiB`, `free after weights 179.06 MiB`, `planned slack 1.06 MiB`
(= 1,114,112 B = exactly the observed free after the prefill code load), `CUDA Graph memory
2.00 MiB / 4.00 MiB`. Post-weights free is deterministic (187,760,640 across 3 runs).

## 6. Verified memory model (exact, at b=1, prefix-reuse off, chunk 64, MTP3, INT8 KV)

- Available after weights: **187,760,640 B** (deterministic; weights arena 16,288,579,584).
- `h(P) = ceil2MiB(persistent(P)) + 12,582,912 + 4,194,304`;
  `persistent(P) = (17P+1)·135,168 + 53,216,512` (+512 B alignment).
- Per page (64 tokens) per layer: 135,168 B = K 65,536 + V 65,536 + scales 4,096 (FP32, group 128
  dk). 16 text layers + 1 MTP layer (P+1 pages) → 17P+1 layer-pages.
- `persistent` fixed part 53,216,512 B = GDN state 41,287,680 + replay 7,151,616 +
  round/misc 4,777,216, where:
  - GDN state (48 layers, 1 slot): conv BF16 {10240,3} = 2,949,120; recurrent I8
    {128,128,48} = 37,748,736; recurrent scale FP16 {128,48} = 589,824.
  - Replay (width=draft+1=4, capacity 1): conv BF16 3,932,160 + value BF16 2,359,296 +
    key BF16 786,432 + gate FP32 73,728.
  - round/misc: prefill_hidden BF16 {5120,64} 655,360 + token_counts I32 {248320} 993,280 +
    tail/rewrite 20,480 + MTP round state ~3,107,740.
- Workspace 11,309,568 B (chunk-driven, identical at 3200 and 4096; single arena, recipes already
  peak-aliased; text_prefill and mtp_prefill tie at the peak).
- Current ceilings: **3200** (P=50, honest slack 1,114,112 B); 3232/3300+ rejected cleanly.

## 7. Phase 4 design (quality-neutral savings, ~3328 ceiling) — pending §2 decision 1

Target: implement both; expected new ceiling P=52 (3328 tokens).

**a) Replay records → I8 + FP16 scale** (`src/core/gdn_replay_records.{h,cpp}`; 7,151,616 →
~3,926,016 B, saves 3,225,600): conv plane I8 1,966,080 + scale per (channel-group-128, width,
layer) 30,720; value plane I8 1,179,648 + scale per (head, dv-row-of-128, slot, layer) 184,320
(matching the bb84f85c recurrent contract); key plane I8 393,216 + scale 98,304; gate stays
FP32 (73,728). Records feed ReplaySSM fold (`tests/.../test_gdn_replay_fold.cpp`) which
reconstructs the I8 state — quality matches the already-chosen state codec.
**b) GDN conv state BF16 → I8** (`core/linear_attention_state.cpp`, `conv_dtype` spec field;
2,949,120 → ~1,497,600 B, saves ~1,451,520): scale per (channel-group-128, width) 480 B/layer.
Conv state is a small persistent state; quantization is a state-precision choice (flag it in the
report; it is *not* a model-weight or KV change).

Per `AGENTS.md` numerical rules: both need the independent naive FP32/FP64 oracle treatment the
I8 recurrent state got in bb84f85c (bit-exact codec contract: `scale16=__float2half_rn(row_max/127.0f)`,
`code=clamp(__float2int_rn(x/scale_f32),−127,127)`, dequant `code*scale_f32`), checked directly,
plus kernel updates (conv snapshot/record record-read sites; replay fold). Suites that must stay
green: `ctest -R 'ninfer_gated_delta_net_test|ninfer_gated_delta_net_replay_record_test|ninfer_gdn_replay_fold_test|ninfer_gdn_replay_records_test|ninfer_gdn_input_proj_conv_snapshot_test|ninfer_gdn_input_proj_conv_record_test'`
plus full build (105 targets). Then: clean 3328 generation with the exact sweep command, confirm
3392 (P=53) rejects cleanly, and that 3200 is unchanged.
